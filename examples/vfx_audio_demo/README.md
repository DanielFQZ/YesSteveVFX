# VFX 音效测试包

程序合成的 0.45 秒下降提示音，无外部采样来源。此音频可自由复制、修改和用于测试。

将本目录复制到 `config/yesstevevfx/packs/`，执行 `/vfx_client reload`，然后执行：

`/vfx_client sound play yesstevevfx:vfx_audio_demo/slash swing`

YSM 动画指令帧：`ctrl.vfx_sound_play('yesstevevfx:vfx_audio_demo/slash', 'swing');`

完整说明：`docs/AUDIO-USER-GUIDE.md`。
