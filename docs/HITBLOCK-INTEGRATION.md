# VFX HitBlock 与 YSS

VFX 会从当前 eyelib 模型的最终动画姿态中读取名称以 `HitBlock` 开头的骨骼，并把其中的 cube 转换成世界空间 AABB。VFX 只提供几何数据，不负责距离、视线、命中去重、伤害或击退规则。

在 YSS 的攻击动画判定段中勾选 **特效碰撞箱**，对应配置会写入：

```json
{
  "use_vfx_hitboxes": true
}
```

启用后，YSS 会分别用当前玩家来源特效的活动 `HitBlock` AABB 和该段模型骨骼盒筛选相交目标，再合并目标进行命中去重。模型盒保持近战距离；VFX 盒允许玩家到目标最多 64 格，并保留视线检查。服务端也必须更新 YSS 且为该段开启此选项，否则远程命中仍会被拒绝。旧配置缺少此字段时默认 `false`。

按 F3+B 可在攻击期间看到 YSS 采样的 VFX 判定线框。64 格只是当前服务端接受范围的上限，实际仍需特效盒与目标相交；服务端目前根据客户端报告的目标 ID 校验范围和攻击段，不独立重算 VFX 动画几何。

使用时应注意：

- `HitBlock` 必须是模型骨骼名称或绑定名称的前缀，大小写不敏感。
- 骨骼的动画位置、旋转、缩放以及特效载体的世界变换都会计入碰撞盒。
- 缩放任一轴为零的骨骼不会产生碰撞盒。
- 固定特效仍会在固定位置提供碰撞盒；跟随特效会随来源实体更新；目标特效会按其目标播放模式更新。
- 需要同时安装 VFX 和 YSS。任意一方缺失时，另一方会安全地忽略这项可选数据。
